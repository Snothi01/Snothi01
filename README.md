## ☁️ Current Focus: Becoming a Cloud Engineer

Working on a live application taught me how much of software is what happens *after* the code is written: data flowing between systems 🔀, integrations failing quietly, and workflows that need to stay reliable.

That's what pulled me towards the cloud. I'm building up my AWS knowledge so I can move from writing features to designing, deploying and securing the infrastructure they run on.

I recently completed the **AWS Certified Cloud Practitioner 21 Day Builder Sprint**, organised by Jcodebook. Over 21 days I worked through core AWS services across compute, storage, networking, databases, security, monitoring, governance and AI/ML.

What I covered:

* 🖥️ **Compute & scaling:** EC2, Auto Scaling
* 🪣 **Storage:** S3
* 🌐 **Networking:** VPC
* 🗄️ **Databases:** RDS (Multi-AZ vs Read Replicas), DynamoDB
* 🏗️ **Infrastructure as code:** CloudFormation
* 🔐 **Security & governance:** IAM, AWS Organizations
* 📈 **Monitoring & auditing:** CloudWatch, CloudTrail
* 🤖 **Analytics & AI/ML:** SageMaker, Bedrock, Rekognition, QuickSight

Next up 👀:

* 🐧 Linux and the command line
* 🚀 Deployment and automation
* 🔐 Deeper cloud security and networking
* 🛠️ Hands-on AWS projects that put these services to work
